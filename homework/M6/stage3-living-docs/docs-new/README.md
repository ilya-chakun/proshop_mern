# Living Documentation — New Docs

This directory contains the living documentation artifacts created during Stage 3.

## Contents

| Folder | Description |
|--------|-------------|
| `specs/` | 4-step module specifications (mcp-feature-flags, rag-query) |
| `adr/` | Architecture Decision Records (3 ADRs from M2) |
| `architecture/` | Architecture overview document |

## Module Specs

Each spec follows the 6-section template:
1. Overview
2. Decision Table
3. Sequence Diagram (Mermaid)
4. Edge Cases (≥ 10 per module)
5. Open Questions
6. Suggested Tests
